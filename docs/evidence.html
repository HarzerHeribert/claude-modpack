How we know

Every measurement

144 measurements, each quoted word for word from the README, the changelog, a lab note or a benchmark write-up, with its 95% range, its runs, model and date, and the raw runs behind it.

The work
Real jobs in open-source code: click in Python, chrono in TypeScript, and real bug reports from SWE-bench Verified. Graded by fixed rules.
The runs
Claude Code without a person at the keyboard, on Opus 5.5, a fresh copy of the code each time. Each condition names exactly which mods load.
The cost
Counted from the transcripts at list prices. On a subscription that is an estimate, not a bill.
The range
A 95% bootstrap range over runs within each job. When it includes no change, we say the difference is not shown. How we measure

144 of 144 shown. Download facts.json

The dot is the measured change, the bar around it the 95% range, the upright line no change. Left of the line is cheaper or fewer.
