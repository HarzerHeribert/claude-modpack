claude-modpack 0.6.0

Claude Code with fewer wasted steps, and a clear view of what it’s doing.

Eight free mods for Claude Code and the modpack that installs them. Every number here was measured on graded runs, including where the pack doesn’t help.

Why it saves

Every step Claude takes (read a file, run a search, make an edit) sends the whole conversation back to the model. That re-reading is most of what a session costs, so the cheapest step is the one Claude never takes. The pack takes out steps that need no thinking.

Re-reading, priced

Every request re-reads the context. Move the sliders.

Worked out from Opus 5.5’s list prices: $0.20 per million tokens read from the cache, $8 to write them (one-hour lifetime). List prices. An illustration: what each step adds is your choice here, not a measurement.
