Eight mods and the pack

Each works on its own, finds the others through Claude Code itself, and switches off with /mods <mod> off.

ModWhat it doesKindMeasured
cellsSeveral edits and their test run in one stepflow+8.9%cost of taking it out
lsp-plusA search for a name answered by the language servercode intelligence−25%requests on a rename
seekLook around in few, lean stepscost−11.9%fresh, against the pack
delegateA cheaper model builds what you approvedcost−22%a feature, handed off
routeFeature and test work goes to the cheaper model by itselfcost, opt-in−14.2%eight jobs, against the pack
smart-compactKeeps the cache warm, or compacts before it expirescostworked out, not measured
statuslineOne line under the prompt with what mattersinterfaceinterface only
etaJobs with a percentage and a finish time above the promptinterfaceinterface only
modpackInstalls the others, switches them, keeps them currentthe pack10 suntil a hanging hook is skipped

How they fit together

  • statusline is the line the others write on: smart-compact adds its ready or cold there.
  • lsp-plus answers a search for a name from the language server and warms each language’s server at the start, so cells’ lookups and delegate’s look at where a change reaches meet a warm server.
  • cells makes its edits through the Edit tool, so lsp-plus’s check for docs that still use a removed name runs on them.
  • smart-compact keeps long sessions’ caches warm, where delegate and cells pay most.
  • route gives delegate’s order for feature and test prompts; seek’s setting rides with the same prompt.
  • eta shows background jobs, including those a cell starts.

What makes the cut

A mod joins the pack only when it was measured and cost no quality, saves cost or time or makes the work more reliable (or only adds interface), works with the others and without them, and stays quiet where it has no proof. Every option of every mod: the README.
