mods / cells

cells

Several edits and their test run in one step.

flowv0.4.3+8.9%cost of taking it out

The problem

When Claude makes two edits and then runs the tests, each can be a step of its own, and every step re-reads the whole conversation. Models also often change files with a script through the shell: cheap, but you see no diff and /rewind cannot undo it.

What it changes

Claude can write a short program, a cell, whose calls are the real tools: read, edit, run. Several edits and their test run happen in one step. Every edit still goes through Claude Code’s own edit tool, so you see each change, your permission prompts apply, and /rewind undoes it.

The cell is the example from run_cell’s own description; the notes are the ones cells attaches when a request did no more than a check after edits or one edit in a row (each also names the seconds the request took, left out here). Worked out from Opus 5.5’s list prices: $0.20 per million tokens read from the cache, $8 to write them (one-hour lifetime). List prices.
