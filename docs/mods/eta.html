mods / eta

eta

Jobs with a percentage and a finish time above the prompt.

interfacev0.2.2interface only

The problem

A long test run in the background is a black box: is it at 10% or at 90%, and will it be done before your coffee?

What it changes

Background jobs show above the prompt as soon as Claude starts one. With track_progress, eta reads the job’s output live and adds a bar, a percentage and an estimated finish time. Before progress is readable, Claude’s own guess stands in, marked as such. A finished job leaves; a failure stays until you write again.
