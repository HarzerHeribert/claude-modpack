lsp-plus

A search for a name, answered by the language server.

It comes with the pack and is on from the start.

The moment

You ask Claude to rename a function, or to find out who calls it.

Without lsp-plus

Claude searches the text with grep. Grep returns every line that contains the name: imports, calls, the definition, a comment, a namesake somewhere else. It doesn’t say which function each call sits in, so Claude opens the files and reads on to find out.

With lsp-plus

When Claude’s search looks for a name in your code, lsp-plus asks the language server, the engine your editor uses, and attaches its exact answer to the search result: every caller, named by its function. Claude needs no extra step, because the answer is where it was already reading.

Turn it on or off

Run /lsp-plus:setup once in your project to install the servers. /mods lsp-plus off turns it off. Every option is in the README; the code is in lsp-plus/.
