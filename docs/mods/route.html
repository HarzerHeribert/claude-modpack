The problem

A hand-off pays on features and tests, and costs more on everything else. Claude does not make this call by itself: it never hands off unasked. So the question is when to tell it to.

What it changes

A small, fast classifier reads each prompt you send. Only feature or test work gets the order to hand it to delegate’s worker before Claude reads the code; everything else stays with Claude. It is off until you turn it on and give it a key: from then on, the start of each prompt goes to the classifier, a US service.

Around a hand-off

Claude’s own requests in the 16 routed runs of the feature and coverage tasks: on average 1.6 looking around before the hand-off, the hand-off, and 2.5 after it. With the verified report and the order to hand off before reading: two, the floor. Lab notes 10.
