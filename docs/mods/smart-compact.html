mods / smart-compact

smart-compact

Keeps the cache warm, or compacts before it expires.

costv0.1.2worked out, not measured

The problem

When you step away, the conversation’s cache expires: after an hour on a subscription, five minutes on an API key. Your next prompt then writes the whole conversation to the cache again, at a higher price.

What it changes

A few minutes before the cache expires, smart-compact either keeps it warm with a cheap request, or compacts the conversation while the cache is still warm, whichever costs less. Small sessions it leaves alone. The status line says whether the session is ready or has gone cold.

See it work

While you are away

smart-compact’s policy, run on your numbers.

Cache lifetime

smart-compact’s own policy (the smart strategy with its defaults) and price formula, run on Opus 5.5 list prices. The cache lives an hour on a subscription, five minutes on an API key. Worked out, not measured: the README says so too.

Words used here: cache write and its lifetime, cache read, compaction.
