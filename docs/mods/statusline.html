statusline

One line under the prompt with what matters.

interfacev0.2.1interface only

The problem

While you work, it is hard to see how full the conversation is, or how much of your plan’s 5-hour and weekly limits you have used.

What it changes

One line under the prompt: the model and its effort, how full the context is, the plan’s 5-hour and weekly use with when each resets, and what other mods add, such as smart-compact’s ready or cold. Narrow terminals drop the least important parts first.

See it work

The line at any width

The statusline mod’s own rules, in this page.

⏵⏵ auto mode on

The line’s own rules, ported from the mod: tones (quiet under half, plain past it, amber from 80%), segment priorities and how a narrow line drops them. The values are an example; the auto-compact point here is 800k tokens.

In a real session

Words used here: context.

What we measured

No cost measurement: statusline only adds interface, which the pack’s rules allow. It draws nothing in a headless run, so the benchmarks never see it.

Off or on: /mods statusline off · Options: README · Setup: SETUP.md · Code: statusline/
