claude-modpack 0.9.0, free and open source

Claude Code with fewer wasted steps, and a clear view of what it’s doing.

/plugin install modpack --marketplace HarzerHeribert/claude-modpack

Paste it into Claude Code and answer y. Then /modpack:setup sets up the rest with you, or follow SETUP.md by hand.

Eight small, free mods that take out the steps that need no thinking. We measured each one on graded runs before it shipped, including where it doesn’t help.

An hour into a session

You have been working with Claude for an hour. By now the conversation holds most of your project: every file it opened, every test it ran. You ask for one more feature.

Claude reads a file, then another. It runs a search, makes an edit, runs the tests, makes another edit. Each of those is a step, and every step sends the whole conversation back to the model to be read again, from the top. In a session that size, the re-reading alone costs about four cents$0.044$0.044

So a long session doesn’t get expensive because Claude writes a lot. It gets expensive because it takes many small steps, and each one pays to read everything again.

What the pack changes

Eight small fixes. Each one waits for a moment where Claude would take a step that needs no thinking, and takes it out, or hands the work to a cheaper model.

  1. When Claude makes a few edits and runs the testsThey happen in one step, and every edit still shows as a diff you can undo.cells
  2. When Claude looks around before a changeIt is asked, in your name, to look in few, lean steps.seek
  3. When you ask for a text of at most so many wordsIt is asked, in your name, to land the length in one draft.draft
  4. When you approve a planA cheaper model builds it, and the result is checked before Claude reports.delegate
  5. When you ask for a feature or testsThe work goes to that cheaper model by itself. Off until you turn it on.route
  6. When you step awayYour session is kept ready, or tidied up before it goes cold, whichever costs less.smart-compact
  7. While you workOne line under the prompt shows how full the conversation is and how much of your plan is left.statusline
  8. When a long job runsA bar and a finish time appear above the prompt.eta

And one switchboard, the modpack: /mods turns any of them off or on, right away.

How we know

We gave Claude real jobs in an open-source project, from a one-line lookup to building a feature, and ran each one with the pack and without. Hidden tests graded every result. Then we compared what the runs cost.

We kept a mod only when it paid. Far more ideas didn’t: hints Claude never followed, a saving that left more text behind than it saved, a checklist that turned green on unfinished work. They are in the graveyard with the numbers that stopped them, because they taught us more than what worked.
